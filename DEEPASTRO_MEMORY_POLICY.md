# DEEPASTRO INTELLIGENCE UPGRADE 3.0: MEMORY & SOVEREIGNTY POLICY

## 1. Sovereignty and Consent Mandate
User memory in DeepAstro is strictly sovereign. Memory is never created silently or covertly based on conversational guesswork. Personal biographical facts are committed to permanent memory **only when explicitly stated or confirmed by the user**.

## 2. Memory Categories and Governance
1. **`EXPLICIT_FACT`**: Objective facts explicitly provided by the user (e.g., current location, industry of work).
2. **`USER_PREFERENCE`**: Explicit display preferences (e.g., technical depth: Expert, preferred ayanamsha).
3. **`USER_GOAL`**: Forward-looking objectives confirmed by the user (e.g., preparing for a career transition in Q4).
4. **`USER_EVENT`**: Historical life milestones with verified dates (e.g., relocation in 2018, graduation in 2021).
5. **`USER_DECISION`**: Recorded options and choice outcomes logged by the user during decision simulations.
6. **`USER_OUTCOME`**: Confirmed real-world outcome assessments used for calibration scoring.

## 3. Strict Prohibitions
- **No Poisoning Across Users**: All memory queries require tenant and user isolation (`WHERE user_id = :userId`). Under no circumstances can facts entered by User A propagate to User B.
- **No Hallucinated Memory**: Speculative statements generated by AI (e.g., "You might be a lawyer") cannot be auto-saved as memory unless the user explicitly confirms them.
- **Right to Erasure & Export**: Users can view, export, and delete any stored memory item at any time via the API or settings interface.
